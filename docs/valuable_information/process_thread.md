# プロセスとスレッド

# プロセス
実行中のプログラムをOSが管理する単位

例）ROS2ノードを別々に起動すると、通常はノードごとに別プロセスになる。

プロセス1：camera_node
プロセス2：image_processing_node
プロセス3：motor_control_node

OSは、それぞれのプロセスをCPUコアに割り当てる。

CPUコア1 → camera_node 
CPUコア2 → image_processing_node
CPUコア3 → motor_control_node

プロセスは基本的に独立したメモリ空間を持つ。

## 特徴
* 複数のCPUコアを利用しやすい
* 1つのプロセスが停止しても、他へ影響しにくい
* メモリ使用量が大きくなりやすい
* プロセス間のデータ通信に負荷がかかる

---

# スレッド

スレッドとは1つのプロセス内部にある処理の流れ

1つのプロセス
- スレッド1
- スレッド2
- スレッド3

同じプロセス内のスレッドは、変数やメモリを共有できる。

## 特徴
* プロセスより作成コストが小さい
* メモリ使用量を抑えやすい
* 1つのスレッドの以上がプロセス全体へ影響することがある

# プロセスとスレッドの違い
| 項目 | プロセス | スレッド |
| --- | ----| ----|
| OSから見た単位 | 実行中のプログラム | プロセス内部の処理 |
| メモリ | 基本的に別々 | 同じメモリを共有 |
| 作成コスト | 基本的に別々 | 同じメモリを共有 |
| メモリ使用量 | 大きい | 小さい |
| 独立性 | 高い | 低い |
| CPU並列化 | しやすい | 言語や処理による |
| 障害の影響 | 分離しやすい | 全体へ広がりやすい |
