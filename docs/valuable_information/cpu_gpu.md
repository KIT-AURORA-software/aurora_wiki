# CPUとGPU
# CPU
CPUはプログラムの命令を実行する装置

以下のような処理を担当
* ROS2の通信
* センサデータの取得
* モータへの指令
など

CPUの中には複数のコアがあり、複数の処理を同時に実行できる.

CPU
- コア1
- コア2
- コア3
- コア4

4コアCPUだと複数のプロセスを異なるコアに割り当てて並列実行できる。
---

# GPUとは
GPUは、同じ種類の演算を大量に並列実行することが得意な装置

特に、行列計算や画像処理、深層学習に向いている

CPU
* 少数の複雑な処理が得意
* 条件分岐が得意
* ROS2通信や制御に向く

GPU
* 大量の同じ計算が得意
* 画像認識やAIに向く

# CPU実行とGPU実行の切り替え
CPUとGPUの切り替えは、多くの場合コードや設定で指定する。
ただし、使用するライブラリがGPU実行に対応している必要がある。
